# Python Command-Line Assistant

A modular Python-based command-line application designed to demonstrate fundamental programming concepts through the development of practical, interactive utilities.

The project emphasizes clean code, modular architecture, input validation, error handling, testing, and version control using Git and GitHub.

## Features

### Completed
- **Calculator:** Perform basic arithmetic operations, including addition, subtraction, multiplication, and division.
- **Random Number Generator:** Generate random integers within a user-defined range.
- **Unit Converter:** Convert between Celsius and Fahrenheit, meters and feet, and kilograms and pounds.

### In Development
- **Text Analyzer:** Analyze user-provided text, including word counts, character counts, vowel counts, and sentence counting.

### Planned
- **Password Generator:** Generate customizable random passwords.
- **To-Do List:** Create and manage tasks through the command line.
- **Additional Utilities:** Explore file-management tools and other useful features.

## Project Goals

- Strengthen foundational Python programming skills.
- Apply modular programming principles using separate Python files.
- Practice functions, loops, conditional statements, and data structures.
- Implement input validation and exception handling.
- Develop and test individual features before integration.
- Gain experience with Git, GitHub, and feature-based development.
